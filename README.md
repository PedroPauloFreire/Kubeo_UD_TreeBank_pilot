# Kubeo UD Pilot

Prototype corpus of the Kubeo language annotated according to the Universal Dependencies framework.

## About

This repository contains the initial corpus developed during a PIBIC undergraduate research project at the University of Brasília (UnB).

The corpus currently consists of manually annotated sentences extracted from the bilingual educational material *Pamiene Mama Buei-Tukubo*.

## Contents

- `data/kubeo_pilot.conllu`: annotated corpus in CoNLL-U format.
